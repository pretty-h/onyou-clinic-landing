# 온유 피부과 랜딩페이지

가상의 피부과 브랜드 ‘온유’를 위한 반응형 랜딩페이지입니다. HTML, CSS, JavaScript와 Node.js 기본 모듈만 사용하며 별도 패키지 설치가 필요하지 않습니다.

## 주요 기능

- 모바일 및 데스크톱 반응형 화면과 모바일 메뉴
- 진료 프로그램별 필터
- 관심 프로그램 선택 및 상담 준비사항 안내창
- 브랜드 철학, 공간 소개, 방문 안내

실제 병원 정보나 예약 시스템이 연결된 서비스가 아닌 디자인 데모입니다. 상담창은 개인정보를 수집하거나 예약을 전송하지 않습니다.

## 로컬 실행

Node.js가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
node server.cjs
```

브라우저에서 <http://127.0.0.1:3000>에 접속합니다. 서버는 로컬 주소에만 연결됩니다. 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

npm을 사용할 수 있다면 `npm run dev` 또는 `npm start`로도 실행할 수 있습니다.

사진은 Unsplash, 글꼴은 Google Fonts에서 불러오므로 해당 리소스 표시에는 인터넷 연결이 필요합니다.

## 구문 검사

```sh
node --check script.js
node --check server.cjs
```

또는 `npm run check`를 실행합니다.

## 파일 구성

- `index.html`: 페이지 콘텐츠와 상담 안내창
- `style.css`: 디자인과 반응형 레이아웃
- `script.js`: 필터, 메뉴, 상담 안내 동작
- `server.cjs`: Node.js 로컬 정적 파일 서버
- `package.json`: 실행 및 검사 명령

## Git 관리

환경 변수, 인증 정보, 의존성 폴더, 로그, 로컬 도구 설정 및 배포 메타데이터는 커밋에서 제외합니다. 이 프로젝트는 로컬 실행을 기준으로 하며 외부 배포 설정은 포함하지 않습니다.
